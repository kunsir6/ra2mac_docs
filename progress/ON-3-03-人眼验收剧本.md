# 上屏人眼验收剧本（30 秒）

> 目的：把 L3「画面可信」从"我们自证"变成"你亲眼确认"。
> 现在自动化能证明「present 被调用了」，不能证明「屏幕上真的是这幅画」——
> 沙箱没有屏幕录制权限，`screencapture` 拿不到像素。这一份由你来补。

双击这个（或右键 → 打开，首次需要过一次 Gatekeeper 提示）：

## 2. 点「單人遊戲」（对照 `2-single-player-800x600.png`）

用鼠标点右侧第一个按钮。

**期望**：换页到单人游戏选单（窗口可能变成 800×600）。

**这一步最容易失败**——真实鼠标点击这条链路只在自动测试里跑过（合成事件），
真人点击是第一次。如果点了没反应，**不要重复点十几次**，直接跳到第 5 步报告。

想留下证据的话，用这个方式启动，会把每个输入事件打一行日志：

```bash
cd /Users/zhenglk/ai-project/ra2mac/ConcordRTS
CONCORD_INPUT_TRACE=1 ./build-product-mac/app/ConcordRTS.app/Contents/MacOS/concord_runtime
```

然后把日志里的 `[input] kind=... x=... y=...` 那几行发我。


```
② 点单人游戏： 换页了 / 没反应 / 换了但画面不对
```
