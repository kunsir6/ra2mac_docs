## 三、对账结论（六条，按严重度）

### 3.1 【最重】EVO 主线：额度用尽，②③ 已是第三次跳票

EVO-07 四段里 ①④ 已交付（`--version` 自证 + 包内 BUILD-INFO + dmg + 说明书入库），

**这是本轮唯一一处「账目动作先于指标」的判断**：不判掉它，EVO 就会变成第三条 C-02（11 轮零收口）。

### 3.2 【重】S-24 的门开了却还挂 blocked —— 第三次

`S-24`（载具穿步兵冒烟未进门禁）的 blocked 前置写的是「`.inl` 进 HEAD」。而 R58 的 `782e194`
正是「载具穿友军步兵的格级判据入库并接线」，本轮 regress 第 15 条 `vehiclepass` 真在跑、真在红、
且红项**已带前缀门禁**（`known-red 2 条，其中 0 条无前缀门禁`）——DoD 三句全部满足。

**处置**：`S-24` blocked → **done**。这是「结论写进报告 ≠ 改状态」的第三次发作（AUDIT-56 §3.2 是第二次）。
**根因不是健忘**：blocked 条目的重开条件写在 `status` 字段的自然语言里，没有任何东西去比对
「前置是否已成立」。本轮不加门禁（判不出来），但把它写进 §七.2 的建议：**blocked 条目必须把前置写成
可 grep 的断言（文件路径 / 环境变量 / 条数），否则不许挂 blocked**。

### 3.3 【重】重复代码 +8/+10：一份白名单现在有三份

## 六、EVO 主线整体收口判定（`§六.3` 三选一，判 **done**）

**账目**：子项 **4/4 用满**（①`--version` 自证 `9477056` / ②About / ③数据根提示 / ④dmg+说明书 `10013d1`+`b4672b5`），
已用 **2 轮**（R54 / R55），**不再开第 5 个子项**。

- **交付了什么（可复算）**：`--version` 打印版本/架构/编译时刻 + 读包内 `BUILD-INFO.txt`；`pack-dist` ③b 写该文件
  并重签，⑨ 断言「包内二进制的 `package:` 行 == 包内文件」逐字相同，不等即 `exit 1`；`make-dmg.sh` 造「别人机器」
  （指针改成不存在路径）验 `data root NOT found` 与同级目录 `source=sibling`；说明书入库并由 pack-dist 每次覆盖写。
- **未做的行为差异（写清代价）**：①把包拷到没有数据树的机器上双击，**只有一行诊断**，不会出现可读提示/选目录；
  ②没有 About 面板，版本只能靠 `--version` 或包内 BUILD-INFO 看。代价 = 非技术用户拿不到「我该怎么放数据」的引导。
- **为什么不判 blocked 而是 done**：这条线的用户价值（包能自证身份、能跨机说明数据放哪）已交付且有门禁
  （`pack-dist ⑨` 每个包都断）；②③ 的卡点不是工作量而是**判据缺失**（本项目不调 `sendEvent`、Accessibility 未授权），
  它属 C-01 的下游。按 `§六.3①`「整条主线判 done + 剩余段写清代价」处理，剩余段按 `§六.3③` 移出。
- **重开条件**（写进 `deferred.md`）：**C-01（事件分发接 `sendEvent`）落地后**——届时 modal/按钮交互可用真实事件队列验证，
  ②③ 各开一轮即可。
- **同时关闭一条隐性债**：R56 §3.1 指出「EVO-07 两轮主目标在台账里没有行」，本轮它有了行、有了判定，账平。

## 七、给下 5 轮（R62~R66）的三条建议

### 7.1 R62 走**清偿轮**，且必须动产品代码

理由三条同时成立：①比例闸触发（近 5 轮 2:1）→ 禁新增断言；②腐烂预算虽未触发，但 R58 一轮 +1695 行、
其中 `RuntimeShell.cpp` +42、`RuntimeSessionWorld.cpp` +262，两个文件都在 8,000 行红线之上；
③`S-35` 的三份白名单就是现成的删除对象（合并即净减）。

KPI：净增 ≤0 且 regress 不退化（当前基线 `PASS=14 KNOWN-RED=2 RED-NEW=0` / 16 条）。

### 7.2 blocked 条目的前置必须写成可 grep 的断言

`S-24` 的教训：前置写成「`.inl` 进 HEAD」这种自然语言，没有任何东西能比对，结果门开了挂 3 轮。
**新规则**：登记 blocked 时必须写出**一个具体断言**（`git cat-file -e HEAD:src/...` / `regress` 第 N 条存在 /
某个环境变量能跑通），否则不许进 blocked，只能进 `deferred.md`。

### 7.3 比例闸补分母条件（本轮写进 rules）

> 近 4 轮 `fix:` 提交数 ≤1 → 下轮禁止只做基建/断言，必须产出一条**用户可观察的产品行为变化**。

现闸门「近 5 轮 test: ≥2×fix:」在 R53~55（三轮零 fix:）时完全不响，而那是它最该响的时候。
