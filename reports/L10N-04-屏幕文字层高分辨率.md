# L10N-04 屏幕文字层：让系统字体文字按 backing 倍数光栅

日期：2026-11-14 01:1x

## 症状

用户截图（尤里复仇对局，右侧侧栏 + 悬停 tooltip）：

> 为什么看起来这些文字，显示的都不清晰，有点马赛克的感觉

红框圈的是整个侧栏建造区，焦点是 tooltip「灰熊坦克」。

## 先把"糊"拆成三层

| 层 | 事实 | 判据 |
|---|---|---|
| 截图尺寸 | 1824×1144，= 2048×1280 × 0.8906（非整数缩小） | 侧栏 168 逻辑 px ×2 ×0.89 = 299，实测 300 |
| 窗口 | 1024×640 逻辑 @ backingScale 2.0 → 2048×1280 物理 | `[cocoa] frame`：`view=1024x640 scale=2.0 img=1024x640` |
| 帧缓冲 | **1024×640 的 1x 位图**，由 `contentsScale=2` + `magnificationFilter=Nearest` 整块放大 2 倍 | `RuntimeAppleWindowSurface.mm` 建窗口段 |
| 文字来源 | tooltip 走 `DrawTextW` → compat 的 CoreText 光栅 → **50% 阈值切 1-bit** | `RuntimeWin32CompatText.cpp` 的 `kInkThreshold=128`，文件头决策 (4) |

三条叠加：15px 汉字 → 二值化丢掉全部中间调 → 整块放大 2 倍（每像素变 2×2 方块）
→ 截图又被 0.89 非整数重采样糊一圈。

原版在 800×600 CRT 上是 1 物理像素对 1 画面像素，还有显像管光晕；现在是在
1800px 宽的屏上看一张 1024px 的图，像素感必然更暴露。

## 为什么 1-bit 是"故意的"

`RuntimeWin32CompatTextInternal.h` 写明：GDI 文本必须支持 `R2_XORPEN` 的
"画两遍还原"，部分透明混合没有精确逆运算，所以只能 50% 阈值。这不是偷懒，
是 GDI 语义合同。**所以修法不能是"把阈值改掉"**，那会同时破坏
measure==draw、ROP2 和 XOR 文本可逆。

## 方案：把系统字体文字从帧缓冲里摘出来

帧缓冲保持 1x（动全部 SHP 素材代价不成比例），只把**系统字体文字**单独
按 backing 倍数重新光栅到一张透明位图，由 Cocoa 贴成独立 CALayer：

```
drawTextRun ──capture──▶ textlayer::Run 队列
                              │  present
                              ▼
                     rasterizeGlyphCoverage（2x 字号，8-bit 覆盖）
                              │
                              ▼
                   BGRA 预乘位图 → CALayer.contents
```

关键取舍：

1. **capture 打开时 drawTextRun 只登记不画像素。** 两边都画会出重影，
   而且 1x 方块字会从 2x 字形缝隙里透出来。
2. **capture 只在真实上屏后打开**（`present` → `setPixelScale`，判据 `scale > 1.01`）。
   所有离屏 smoke 的 BMP 取证不经过 present，因此永远走原来的 1x 合成，
   取证口径完全不变。
3. **只在内容变化时重建**（对全部绘制上下文做 FNV-1a 签名）。静止界面 0 开销；
   金币数字变化时只清上一帧的脏矩形，不整屏 memset。
4. **runs 为空时保留上一张，但连续三帧空就清空。** 前者防"某帧没重绘导致整屏文字消失"，
   后者防"切到无字界面后 tooltip 残留"。

## 落点

| 文件 | 改动 |
|---|---|
| `compat/win32/src/RuntimeWin32CompatTextInternal.h` | 新接口 `rasterizeGlyphCoverage` |
| `compat/win32/src/RuntimeWin32CompatText.cpp` | `rasterIntoCoverage`：与 `rasterInto` 同格子语义，8-bit 覆盖 + 按 cell 像素尺寸取字号（真的重新光栅，不是放大掩码） |
| `compat/win32/src/RuntimeWin32CompatTextLayer.{h,cpp}` | 新增：登记、签名、脏矩形、合成、PNG 取证 |
| `compat/win32/src/RuntimeWin32CompatGdi.cpp` | `drawTextRun` 开头加 capture 分支（5 行） |
| `compat/win32/src/RuntimeAppleWindowSurface.{h,mm}` | `updateTextLayer` + `gTextLayer` sublayer + `dumpLayerTree` |
| `cmake/PlatformApple.cmake` | 源文件清单 +1 |

边界仍是"裸指针 + int"，`TextLayer.cpp` 不 include `windows.h`。

## 判据

1. **文字层本身**：`CONCORD_TEXTLAYER_DUMP=<dir> textlayer.png`
   实测 `runs=1 glyphs=6`（金币 200000），字形边缘有灰阶。
2. **合成结果**：`CONCORD_LAYER_DUMP=<dir> layer-N.png`（`renderInContext:`，
   不过 WindowServer，因此不受"无屏幕录制授权"影响）。
   实测底图 + 金币对齐，无重影、无遮挡。
3. **中文**：探针跑 `灰熊坦克 193615`（黄字黑底），2x 下笔画分明、有抗锯齿，
   验证后探针已删除。
4. **回归**：`bash ra2mac_docs/scripts/regress.sh` → **10 PASS / 1 KNOWN-RED / RED-NEW=0**
   （KNOWN-RED 是 slave miner 那段既存夹具，与本轮无关）。
5. **打包**：`pack-dist.sh --bin build-universal/concord_runtime`，min-macos 12.0 一致，
   `--smoke-test rc=0`。

## 回退

- 1x 屏：`scale <= 1.01` 自动不接管，零行为差异。
- 想强制关闭：目前只有"1x 屏"这一条自动判据；如需运行期开关，
  在 `setPixelScale` 前加一个环境变量判断即可（本轮没加，避免又留一个探针）。
