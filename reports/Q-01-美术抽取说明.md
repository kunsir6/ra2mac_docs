# Q-01 美术抽取说明（artmd 派生 → MIX 精确抽取）

本轮把「单位/建筑美术」从原始 MIX 归档里按 **art*.ini 段名派生 + Westwood CRC32** 精确抽取到
`ConcordRTS-GameData`，产物是可直接被资产层消费的散文件树 + 机器可读清单。
**不改任何 ConcordRTS 源码**，只在仓库外的打包脚本里加了一个阶段。

## 1. 命名从哪来

MIX 条目只存 32 位文件名哈希、不存名字，所以「按名提取」必须先能推导出名字。
推导源头是两份 INI（都已落在 `mix_exports` 里）：

| 来源 | 段数量 | 提供了什么 |
| --- | --- | --- |
| `ra2md/localmd/artmd.ini` | 1428 | 单位/建筑的 art 段名、`Image=`、`NewTheater=` |
| `ra2/local/art.ini` | — | 基础版 art（YR 覆盖不到的段落） |
| `ra2md/localmd/rulesmd.ini` | 1419 | 单位 ID、`Image=`（如 MTNK → GTNK） |
| `ra2/local/rules.ini` | — | 基础版 rules |

推导规则：**段名本身 + `Image=` 的值**都作为候选基名（共 2228 个），
再对每个基名试 9 个扩展名：`.vxl .hva .shp .tem .sno .urb .ubn .des .lun`。

关键坑：`artmd.ini` 只是 **YR 覆盖层**，`[GTNK]`/`[HTNK]`/`[E1]` 这些段根本不在里面
（它们在基础版 `art.ini` 里，而单位 ID 到 art 段名的映射还在 `rulesmd.ini` 的 `Image=` 上）。
只读 artmd 会漏掉大半单位——实测 95 个车辆单位里只能解析个位数。

## 2. 第二族候选名：NewTheater 兄弟名

`NewTheater=yes` 有 780 段。这些建筑的剧场变体**不是加后缀，而是换基名的第 2 个字符**：

```
GAPOWR.SHP  16416 B  ra2/snow.mix      (雪地)
GGPOWR.SHP  16416 B  ra2/generic.mix   (通用/温带默认)
```

两者尺寸相同、**md5 不同**（`f63fc2bd…` vs `19824851…`），`--inspect-asset` 都是 142×110 的 SHP，
即同一建筑的两种剧场美术。对 `GAPOWR` 枚举全部 36 个字符位，数据里只存在 `A` 与 `G` 两种。

因此脚本再派生一族候选名：第 0 字符 ∈ `GNCY` 且长度 ≥4 的基名，把第 1 字符替换为
`G A U D L N T`（字母集取自项目自身 `newTheaterCharForExtension` 的映射），
命中才落盘。这一族贡献 **1383** 个文件，占总量的 35%。

> 反讽之处：项目现有映射是 `.tem→'t'`，会去找 `GTPOWR.SHP`——**56 个归档里都不存在**。
> 温带默认图实际是 `GG*`。已立 **Q-02** 跟进（属 mac/win 共用资产层，改动需谨慎）。

## 3. 落盘布局

```
local_data/resources/mix_exports/art/
    base/      747   来自 conquer.mix / generic.mix / local.mix / localmd.mix 等非剧场归档
    temperat/  471   来自 temperat.mix / isotemp.mix
    snow/      745   来自 snow.mix / isosnow.mix / snowmd.mix / isosnomd.mix
    urban/     472   来自 urban.mix / isourb.mix
    urbann/    521   来自 urbann.mix / isoubn.mix / isoubnmd.mix
    desert/    486   来自 desert.mix / isodes.mix
    lunar/     467   来自 lunar.mix / isolun.mix
```

分组名 **取自归档文件名**，不猜剧场后缀。同一基名在不同剧场是不同文件，
分目录存放才不会互相覆盖（平铺会静默丢 60% 的剧场图）。
文件名一律小写，扩展名保留原样（`.SHP` 与 `.SNO` 是游戏里两种并存的形式，不做改名）。

清单：`local_data/art-inventory.json`，每条含 `name / from(归档) / group / derive / to / bytes`，
可复算、可追溯每个文件出自哪个归档。

## 6. 尚未验证 / 下一步

- 引擎**尚未真的从 `art/` 加载任何一张图**：资产层的松散文件索引是 `recursive` 扫描，
  理论上能按名命中子目录，但没有消费方（渲染侧）实跑过。
- 剧场字符集合只对 `GAPOWR`/`GAPILE`/`GAWEAP` 做了全字符枚举，`G` 之外是否还有别的
  兜底字母（如 `N` 新城市、`D` 沙漠）样本不足；Q-02 要用 inventory 反查一遍。
- `hva` 一律 88 字节（1 section / 1 frame 的单位变换），后续如发现需要多帧变换再单独查。
- 步兵 `.shp` 的 `Sequence=`/`LoopCount=` 动画切帧未做，属渲染侧任务。
