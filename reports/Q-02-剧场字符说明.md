## 一、两套约定并存（这是问题的全部）

同一批 RA2 素材里，"温带"在建筑名与地表名里用的是**两个不同的字符**：

| 用途 | 温带文件 | 温带字符 | 其它剧场 |
|---|---|---|---|
| **建筑 SHP** | `art/base/gg*.shp`（28 个） | **G** | `art/snow/ga*`（65 个）= A |
| **地表 overlay** | `art/temperat/gtsand.shp`、`gtwall.shp`、`ntwall.shp` | **T** | `art/snow/gasand.shp` = A |

复算命令（在 `ConcordRTS-GameData/local_data/resources/mix_exports` 下）：

```bash
ls art/base/gg*.shp | wc -l          # 28
ls art/snow/ga*.shp  | wc -l         # 65
ls */gtpowr.shp */ggpowr.shp         # 只有 base/ggpowr.shp；gtpowr 不存在
ls art/temperat/*sand.shp            # gtsand.shp（地表温带）
ls art/snow/*sand.shp                # gasand.shp
```

所以 `newTheaterCharForExtension(".tem")` 这类"一个函数服务所有用途"的写法，
**无论返回 't' 还是 'g' 都必错一边**。上一版返回 't'（对地表对、对建筑错）。

## 二、缺陷的真实影响（不是"缺图"）

`structureAssetFileCandidates` 的候选顺序是：

1. `<首字母><剧场字符><其余>.shp`
2. `<首字母>g<其余>.shp`（温带兜底）
3. `<原名>.shp`

旧映射下温带建筑的**首选名永远不存在**（`gttech.shp` / `ntweap.shp` / `ytrock.shp`），
但第 2 条兜底把它救了回来。于是：

- `Missing SHP` 一直是 **0**（改动前后都是 0）—— 任务 detail 里"温带建筑报缺图"**不成立**；
- 代价是每个温带建筑每次解析都白探一个不存在的文件；
- 更危险的是：这个兜底一旦被删（"反正首选名就能命中"），整片温带建筑立刻缺图，
  而所有现有统计都不会提前报警。

复刻规则的对照（artmd.ini 1428 段，`NewTheater=yes` 的 769 段）：

```
旧规则第一个候选名不存在的段数: 362 / 769
旧规则靠 gg* 兜底才命中的段数: 598
新规则第一个候选命中 art/base/gg*: 21
gt* 命中数: 0
```

## 三、改了什么

`src/assets/preview/MapPreviewExporter.cpp`（单文件）：

1. `newTheaterCharForExtension` 拆成
   `structureTheaterCharForExtension`（`.tem→'g'`）与
   `overlayTheaterCharForExtension`（`.tem→'t'`）。
2. overlay 路径的兜底候选由 `'g'` 改为 `'t'`（`gg*` 对地表永远不存在）。
3. `artIdSupportsNewTheater` 的第二个字符集合补上 `'G'`
   —— `GGPOWR` / `NGYARD` 这类 art id 自己就是温带，旧门禁把它们判成"不支持新剧场"。

## 五、给下一轮的判据

如果要证明"渲染侧也修对了"，需要一个**首个候选命中率**的观测点，而不是"最终是否命中"：

- 统计 `candidates[0]` 是否存在（存在/不存在），按 theater 分组打点；
- 温带地图上该值应为 100%（`gg*` 就在 `art/base`），雪地图 100%（`ga*`）；
- 只统计最终命中率的话，兜底会把任何首选名错误都掩掉 —— 这是本轮最贵的教训。
