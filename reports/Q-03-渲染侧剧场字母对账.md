## 一、决定性实验（先给结论）

温带到底是 `T` 还是 `G`，不需要推理，看文件在不在（`ConcordRTS-GameData/local_data/resources/mix_exports/art/`）：

| 名字 | 存在情况 | 说明 |
|---|---|---|
| `cthosp.shp` | **art/temperat/ 存在** | 温带城市医院 |
| `cghosp.shp` | **不存在**（任何目录） | |
| `ctoild.shp` | **art/temperat/ 存在** | 温带油井 |
| `cgoild.shp` | **不存在** | |
| `ctairp.shp` | **art/temperat/ 存在** | 温带机场 |
| `cgairp.shp` | **不存在** | |
| `caairp.shp` | art/snow/ 存在 | 雪地机场 |
| `ggpowr.shp` | art/base/ 存在 | 通用电厂 |
| `gtpowr.shp` | **不存在** | 温带电厂图**没有单独出** |

结论：

- **温带的剧场字母是 `T`**（`ct*` 203 个文件全在 `art/temperat`）；`G` 只是**通用兜底**。
- 民用/城市建筑（`C` 类）只有 `CT`，**没有 `CG`**。所以把温带字母改成 `G` 之后，
  `CAAIRP` 的首选会变成不存在的 `cgairp`，最后回落到 `caairp`——**温带地图上的城市建筑整片画成雪地图**。
- 军事建筑（`G` 类）确实只有 `GG`（`gt*` 从未出图），所以"温带建筑=G"在 G 类上"看起来对"，
  但那是因为兜底接住了，不是字母对。

**因此撤回两条记录**：`1dc77df`（Q-02）里的"建筑温带 = 'G'"，以及 RUNLOG 2026-11-11 00:16 我写的同一结论。
对端随后独立立了 **Q-04**（"候选序列改回 [剧场字母, 通用 G]"），方向正确，本轮认同。

| theater | 建筑字母 | 地表字母 | 段数 | 首个候选命中 | 走兜底/字面命中 | 无解 |

| temperate | T | T | 800 | **245** | 379 | 176 |

## 三、代码改了什么

新增 `src/data/art/TheaterResourceLetters.h`（平台无关、无 IO、header-only），三个调用点全部改为委托：

| 位置 | 改法 |
|---|---|
| `src/assets/preview/MapPreviewExporter.cpp` | `structureTheaterCharForExtension` / `overlayTheaterCharForExtension` / `artIdSupportsNewTheater` 变薄壳；结构候选改用 `theaterResourceNameCandidates` |
| `src/render/core/RuntimeProductionResources.cpp` | `newTheaterCharForExtension` / `artIdSupportsNewTheater` 变薄壳；候选序列改用同一函数（**这是产品渲染真正走的那条**） |
| `src/render/core/RuntimeMapRenderer.cpp` | 对象图候选序列改用同一函数 |

`RuntimeMapRenderer.cpp:1344` 原来只是**调用** `RuntimeProductionResources.cpp` 里的函数，不是第三份复制；
真正的复制是"预览一份 + 产品一份"。本轮之后只有表里一份。
