## 二、几何对账（已量化，结论是"对"）

| 项 | 正式版 | 当前实现 | 判定 |
|---|---|---|---|
| 侧边栏宽度 | 168 px（`side1/2/3.shp`、`radar.shp` 全部 168 宽） | 真实窗口实测 856→1024 = **168 px** | 一致，1:1 不缩放 |
| 遭遇战背景 | `bkgdmdy.shp` 632×568，800×600 客户端下正好填满 `800-168=632` | `runtimeMenuBackgroundLayout`：客户端 <1024×768 用 bkgdmd 632×568 居中于 contentRect | 一致 |
| 主菜单背景 | 客户端 ≥1024×768 用 `bkgdlgy.shp` 856×736 | 同函数，640 高仍走 632×568 中图 | 合理（640 < 768） |
| 载入画面 | 800×600 原始页（`ls800*.shp`），坐标按 800×600 硬编码 | `runtimeMatchScoreScaledRect(client, {0,0,800,600})` 等比铺 | 一致 |
| 雷达区 | `radar.shp` 168×110 | 侧栏顶部大块蓝色鹰徽区，高度目测相符 | 形态一致 |

之前怀疑"背景被横向拉伸"——**证伪**。632×568 在 800×600 里正好铺满左侧，真实窗口 1024 宽时是居中留边，不是拉伸。

## 三、可确证的差异（建议调整）

### 3.1 FPS 叠加层默认常显（原版没有）—— **已废弃（第 69 轮核对）**

> **本条结论已失效，不要再据它动手。** 2026-11-12 当天就由 `c1ccfe6`
> 「fix: FPS 叠加层改为默认关闭（--show-fps / [Options] ShowFps 才画）」修掉了：
> `RuntimeConfig.h:88 fpsOverlayEnabled = false`，三处提交路径（`RuntimeShell.cpp:29315/29388/29400`）
> 全部 `if(...fpsOverlayEnabled)` 才画，`RuntimeMain.cpp:399` 是 `--show-fps` 的 opt-in 入口。
> 留在这里只为说明「报告里的结论没有失效日期，就会在台账里活成事实」——见 `reports/FIX-69` §2.1。

- 证据：`src/runtime/performance/RuntimeFpsDisplay.inl` 的 `drawRuntimeFpsDisplay` 在每次提交帧后被**无条件**调用
  （`RuntimeShell.cpp` L29275 / L29347 / L29358 三处提交路径全调），窗口左下固定 96×22，底色 `RGB(19,29,39)`、白字。
  真实窗口截图左下角即 `FPS: 60`。
- 正式版：没有这个面板。
- 评估：**要改**。改成默认关，`--show-fps` 或 `[Options] ShowFps=yes` 才画。
  注意 `RuntimeMainFrameContract` 里有"FPS panel exists"的断言，改的时候要同步（否则契约红）。

### 3.2 `--skip-skirmish-menu` 进的是战役地图，拍不到真实开局

- 证据：启动日志 `DefaultMap=.../multimd/2peaks.map`，`Triggers: 7 / Structures: 10 / Units: 0 / Infantry: 0 / Players: 1`，
  地图 `[Basic]` 里写着 `NextScenario=GDI2A.map`、`Official=yes`；`--skirmish-build-smoke-test` 直接报
  `modeRules=no alliesAllowed=no mustAlly=no ownerFactory=no unholy=no megawealth=no`。
- 现象：出图里没有基地车、没有己方建筑、侧边栏建造格全空。**这不是缺陷，是地图/路径不对**，
  但它导致"游戏内 HUD"这一整块永远没有可信对照物（本次就卡在这里）。
- 评估：**要改**，优先级高于任何像素修补。要么让 skip 路径走真正的遭遇战 bootstrap，要么把 DefaultMap 换成标准多人图。
  这和队列里已有的 EVO-03（diagnostics 驱动）是同一件事的两面，建议合并推进。

## 五、非缺陷项（已排除，避免重复返工）

- **鼠标指针**：游戏自绘（`drawRuntimeMouseCursorOverlay` + `mouse` atlas + `mousepal`），截图里那个白箭头就是 RA2 默认光标，不是 macOS 箭头。
- **"AI" 与"无冷却"勾选框**：原版没有，是本项目扩展。保留可以，但属于"非原版内容"，界面若要标"还原正式版"需要说明。
- **菜单字体/字形**：L10N-02 已处理，本次不再重复。
- **侧边栏建造格全空**：裸地图没有己方建造厂，空是正确行为（叠加 §3.2）。

## 六、美术量级差距（记录，不排期）

拿 Steam 官方 1920×1080 战斗图对比 `--render-smoke-test` 出的 960×640 帧：

| 维度 | 正式版 | 当前 |
|---|---|---|
| 地形 | 悬崖/海岸/道路/树丛层次丰富，水面色阶过渡自然 | tile 边缘可辨、海岸线是硬拼接，水面单色 |
| 单位与特效 | 密集单位、爆炸、尾焰、弹道拖尾 | 单位是小白点，无拖尾/爆炸，阴影极淡 |
| 建筑 | 基地成片 | 一帧里 structures=0 |

这是内容与渲染深度的差距，不是"不对"，短期不建议动；但它决定了"像不像正式版"的主观感受，需要单独立项（不在本次任务里）。
